# Gaya main

Gaya mengubah cara menimbang keputusan, bukan aturan. Semua gaya tetap tunduk pada `../aturan.md` dan etika di SKILL.md. Kalau pengguna tidak memilih, pakai **seimbang**.

| Gaya | Ringkas | Cocok untuk |
|---|---|---|
| [seimbang](seimbang.md) | Bawaan. Mulung kalau membuka mentung, bertahan kalau ada yang mengancam. | Main biasa |
| [pemungut](pemungut.md) | Agresif mulung, kejar mentung secepatnya, berani pegang tangan tipis. | Lawan pasif, meja 2–3 pemain |
| [tembok](tembok.md) | Bertahan: buang kartu mati, hindari kepentung, buang beban lebih awal. | Sedang memimpin, putaran kaldu |
| [pemburu-joker](pemburu-joker.md) | Simpan joker untuk pentungan 250, kejar nutup pakai beberapa joker. | Tertinggal jauh, butuh ayunan besar |
| [pemancing](pemancing.md) | Membaca dan memancing: buang umpan, pungut kartu pemain yang memimpin. | Lawan manusia yang suka mulung |
| [santai](santai.md) | Main ringan dan ramah, sengaja tidak terlalu tajam, banyak celetukan. | Teman yang baru belajar |

Menambah gaya: buat file baru di folder ini dengan bagian yang sama (Kapan dipakai, Ambil atau mulung, Turunkan, Buang, Joker, Obrolan), lalu tambahkan barisnya di tabel.
